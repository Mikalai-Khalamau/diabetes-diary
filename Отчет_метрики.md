# Отчет по Виктория Метрикс

# Стек технологий: 
Пакетный менеджер Helm, чарт vm/victoria-metrics-single 
VictoriaMetrics
Либы prometheus-client, prometheus-fastapi-instrumentator
postgres-exporter

# Использованные экспортеры:
prometheus-fastapi-instrumentator и prometheus-client встроены в приложение, автоматически собирают метрики рантайма питона и http метрики фреймкворка
postgres-exporter запущен как sidecar контейнер в поде базы данных, подключается к localhost:5432 и отдает метрики СУБД на порту 9187
VictoriaMetrics установлена через Helm чарт, а поды ищутся автоматически через Service Discovery

# Реализованные бизнес метрики:
diabetes_glucose_measurements_total - cчетчик, показывает общее количество сохраненных замеров уровня сахара
diabetes_insulin_injections_total - счетчик с лэйблом insulin_type. Показывает количество инъекций инсулина с разделением на короткий и длинный
diabetes_meal_events_total - счетчик, показывает количество записанных приемов пищи
diabetes_auth_attempts_total - счетчик с лейблом status, показывает количество попыток авторизации, помогает отслеживать неудачные входы
